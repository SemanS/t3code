# Shared memory

Open **Memory** under a workspace project in Work, or search for **Open Memory** in the command
palette. On mobile, open **Settings → Memory** and choose the workspace project. Company knowledge
uses an explicit workspace scope; similar topics in other projects do not grant access.

Record a finding with its source, checkout commit, and relevant topics. Findings without evidence
remain proposed. Use the detail to inspect provenance, conflicting claims, validity, and earlier
versions. **Valid at** asks what applies at a time; **Known at** asks what had been learned by then.
Today's access rules apply to historical queries too.

Select exact versions and preview a projection for a stated purpose. The manifest shows the versions
actually included, required counter-evidence, omissions, and the estimated budget. Previewing it does
not deliver it to an agent. Work and Memory show separate receipts for requested, delivered,
acknowledged, and evidenced use by each session and runtime generation.

Use **Edit, review, or organize** to correct a claim, attach evidence, answer questions, review
decisions, or reorganize topics. Corrections preserve the earlier claim and its history. Restoring a
version creates a new version; it does not remove later history. Publication to another project
requires an explicit target and generalized text with private details removed.

**Keep for Git review** prepares a `.ai` proposal. It remains **pending Git review** until a reviewed
commit is imported. A staged file, a candidate, or an agent-written approval does not establish
approved knowledge.

The project can use legacy, shadow, or memory mode. Returning to legacy preserves memory records and
queued operations. During an outage, **pending locally** means a finding has not been shared; blocked
operations need their version or permission conflict resolved. Open **Pending and blocked local
operations** to inspect the original command and reason, retry it unchanged, or discard it with a
reason after creating a corrected operation against the current version. Agent availability and work continue
independently of the memory store.
